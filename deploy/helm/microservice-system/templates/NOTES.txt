MicroServiceSystem chart (application deploy — not a K8s operator UI).

1. External Postgres / Redis / RabbitMQ (and Mongo if logging enabled) must already be reachable.
2. Apply schemas before traffic:
   - Prefer CI or: docker run --rm -e POSTGRES_* ghcr.io/<owner>/msf-migrate:<tag>
   - Or: --set migrate.enabled=true --set secrets.migratePostgresPassword=...
3. Override secrets (jwtSigningKey, internalApiKey, connection strings, rabbitmq password).
4. Install:

   helm upgrade --install msf ./deploy/helm/microservice-system \
     --namespace msf --create-namespace \
     --set image.repositoryOwner=<owner> \
     --set image.tag=<sha-or-latest>
